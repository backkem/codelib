codelib playground

Write a small JavaScript program, press Run: it executes inside the codelib sandbox, in your browser.

Runs entirely in this tab: StarlingMonkey compiled to WebAssembly, in a Web Worker. Needs a Chromium-based browser. The native library enforces more (a memory cap, fuel, a full egress policy) than this demo, which only enforces a deadline. Source on GitHub
